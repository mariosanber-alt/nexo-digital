- 📦 **Productos Digitales** — 9 servicios
- ⚙️ **Automatización y Software** — 8 servicios

## Estructura del repositorio

- `index.html`, `styles.css`, `app.js`, `data.js` — la web (desplegada con GitHub Pages).
- `metodos/` — 60 carpetas, una por negocio, con el paso a paso completo, prompts, copy y automatización.
- `RESUMEN.md` — resumen completo del proyecto y flujos de trabajo.

## Cómo desplegar

La web está publicada con **GitHub Pages** desde la rama `main` (raíz del repositorio).
Para actualizarla: edita `_data/*.mjs`, ejecuta `node _build/generar.mjs` y haz push.
