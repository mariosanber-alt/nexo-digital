# Comunidad de pago (Discord/Telegram)

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear una comunidad nicho con acceso de pago (networking, recursos, mentoría grupal).

## Quién paga

Profesionales y aficionados de un nicho que quieren pertenecer y aprender.

## Tarifa

5-25 €/mes por miembro

| Campo | Valor |
|---|---|
| Tiempo de entrega | 1-3 meses para lanzar |
| Dificultad | Alta |
| Primer euro | 1-3 meses |
| Método de cobro | Plataforma de membresía (Whop/Skool/Stripe) gestiona cobro recurrente. |

## Material necesario (todo gratis o casi gratis)

- Discord (gratis) o Telegram
- Stripe/PayPal o plataforma (Skool tiene plan gratis limitado)
- Canva

## Paso a paso

1. Elige 1 nicho donde ya haya demanda de comunidad (empleo, IA, trading, fitness, idiomas).
2. Crea el servidor/chat con canales temáticos y reglas claras.
3. Ofrece 1 mes gratis a los 20 primeros por testimonio.
4. Define el valor: recursos exclusivos, sesiones semanales, networking.
5. Cobra 5-25 €/mes por miembro.
6. Entrega contenido recurrente y moderación activa.

## Prompts listos para copiar

### Prompt de calendario de comunidad

```text
Actúa como community manager. Te paso el nicho: [pegar]. Devuélveme un plan de 30 días de comunidad: 4 eventos/sesiones semanales, 10 temas de debate, 5 recursos exclusivos y 3 reglas de convivencia.
```

## Mensajes de captación (copy)

### Post de lanzamiento

```text
👥 Abro la comunidad de [nicho]. Primer mes gratis para los 20 primeros. Incluye: [beneficios]. DM 'COMUNIDAD' para entrar.
```

## Automatización

Discord/Telegram gestionan membresía con bots de pago (o plataformas como Skool/Whop). El contenido se programa semanalmente.

## Dónde encontrar clientes

LinkedIn, X/Twitter, Instagram, YouTube (tu audiencia), comunidades existentes.

## Plan B

Valida con un grupo gratuito antes de cobrar.

## Verificación y viabilidad

Modelo recurrente potente, pero exige trabajo continuo de moderación y contenido. Requiere cierta audiencia o autoridad previa en el nicho.
