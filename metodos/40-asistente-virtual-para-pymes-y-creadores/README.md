# Asistente virtual para pymes y creadores

> 🧑‍💻 **Categoría:** Freelance y Micro-tareas · **Origen:** Método nuevo (creado y verificado)

## Qué es

Tareas administrativas remotas: gestión de email, agenda, facturación, atención al cliente, redes.

## Quién paga

Pymes, coaches y creadores desbordados de tareas operativas.

## Tarifa

12-20 €/hora o 200-600 €/mes (retainer)

| Campo | Valor |
|---|---|
| Tiempo de entrega | Recurrente |
| Dificultad | Fácil |
| Primer euro | 1-2 semanas |
| Método de cobro | PayPal/Bizum o plataforma (Upwork/Fiverr cobran comisión). |

## Material necesario (todo gratis o casi gratis)

- Google Workspace
- Canva
- Calendly
- PayPal/Bizum

## Paso a paso

1. Define 3 servicios concretos (gestión de email, agenda, facturación, soporte).
2. Publica tu oferta en LinkedIn y grupos de emprendedores.
3. Ofrece 1 semana gratis a 2 clientes por testimonio.
4. Acuerda un retainer mensual (p.ej. 10 h/semana).
5. Entrega informes semanales de lo hecho.
6. Escala con más clientes o subiendo tarifa.

## Prompts listos para copiar

### Prompt de propuesta

```text
Actúa como asistente ejecutivo. Te paso el negocio: [sector, tareas que repiten]. Devuélveme: 5 tareas que puedo automatizar o asumir, el tiempo semanal estimado y una propuesta de paquete de 10 h/semana con precio.
```

## Mensajes de captación (copy)

### DM de captación

```text
Hola [nombre], vi que gestionas todo solo/a. Te ofrezco 1 semana de asistencia virtual gratis (email, agenda, facturación) para que veas cuánto tiempo recuperas. ¿Hablamos?
```

## Automatización

Combina con IA (resúmenes, borradores) para hacer más en menos tiempo. Factura con PayPal/Bizum y usa un sheet de horas.

## Dónde encontrar clientes

LinkedIn, grupos FB de emprendedores, Instagram de coaches, Upwork/Fiverr (para empezar).

## Plan B

Ofrece a 3 conocidos con negocio.

## Verificación y viabilidad

Demanda real y creciente (trabajo remoto). La clave es nichar (VA para coaches, para ecommerce, para abogados) y vender retainer, no horas sueltas.
