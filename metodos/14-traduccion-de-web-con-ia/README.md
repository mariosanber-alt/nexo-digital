# Traducción de web con IA

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Traducción de web completa (ES↔EN) con revisión humana y adaptación cultural.

## Quién paga

Pymes con clientes internacionales o turismo.

## Tarifa

Gratis (2 primeros) → 59 € (web hasta 5 páginas)

| Campo | Valor |
|---|---|
| Tiempo de entrega | 72 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- DeepSeek/ChatGPT
- Google Docs
- PayPal

## Paso a paso

1. Elige 2 webs con mala traducción al inglés.
2. Publica el post y manda DMs.
3. Traduce 1 sección de muestra (con notas de adaptación).
4. Envíala como prueba y pide testimonio.
5. Cobra 59 € por web de hasta 5 páginas.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de traducción web

```text
Traduce esta página al [inglés/español] adaptando culturalmente, no literal. Mantén SEO (keywords), tono de marca y CTA. Formato tabla: original | traducción | nota de adaptación si aplica. Página: [pegar].
```

## Mensajes de captación (copy)

### Post de captación

```text
🌍 Traduzco gratis la web de 2 pymes esta semana (ES↔EN) con adaptación cultural, no literal. Solo pido testimonio. DM 'WEB'.
```

## Automatización

El prompt genera la tabla completa; entregas en Google Doc bilingüe por secciones. Revisa siempre con ojo humano (matices de marca).

## Dónde encontrar clientes

LinkedIn de pymes exportadoras, grupos FB de comercio internacional, Google (webs con inglés malo), WhatsApp de conocidos, Cámaras de Comercio.

## Plan B

Traduce tu propio LinkedIn y úsalo de ejemplo.

## Verificación y viabilidad

Las pymes que exportan o reciben turismo necesitan web bilingüe. La traducción profesional es cara; tú ofreces calidad similar por menos con revisión humana.
