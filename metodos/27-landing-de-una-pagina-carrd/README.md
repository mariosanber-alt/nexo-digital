# Landing de una página (Carrd)

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Landing de una sola página (Carrd) para un servicio o lead magnet.

## Quién paga

Freelancers y negocios sin web pero que necesitan un enlace.

## Tarifa

Gratis (2 primeros) → 39 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 48 h |
| Dificultad | Media |
| Primer euro | 48-72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Carrd (gratis)
- Canva
- PayPal

## Paso a paso

1. Crea cuenta en Carrd (gratis).
2. Publica el post y manda DMs.
3. Monta 1 landing de muestra.
4. Envíala como prueba y pide testimonio.
5. Cobra 39 € por landing publicada.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de landing

```text
Actúa como copywriter y diseñador web. Te paso el servicio: [pegar]. Devuélveme: titular, subtítulo, 3 bloques de beneficio, prueba social, CTA, y estructura visual para Carrd (secciones y orden).
```

## Mensajes de captación (copy)

### Post de captación

```text
🌐 Monto gratis una landing de una página a 2 personas esta semana (Carrd, sin código). Solo pido testimonio. DM 'LANDING'.
```

## Automatización

Plantilla de Carrd reutilizable (hero + beneficios + CTA + contacto). El prompt da el copy; tú montas la página.

## Dónde encontrar clientes

Twitter #buildinpublic, grupos FB de freelancers, LinkedIn, Discord de creadores, WhatsApp.

## Plan B

Monta tu propia landing y úsala de portfolio.

## Verificación y viabilidad

Tener un enlace profesional es la primera necesidad de quien vende por DM. Entrega rápida y tangible.
