# Copy de landing page

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Reescritura del copy de una landing (titular, subtítulo, beneficios, prueba social, CTA).

## Quién paga

Infoproductores, SaaS pequeños y coaches con landing que no convierte.

## Tarifa

Gratis (2 primeros) → 49 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 48 h |
| Dificultad | Media |
| Primer euro | 48-72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Google Docs
- PageSpeed/inspección
- DeepSeek/ChatGPT
- PayPal

## Paso a paso

1. Busca 3 landings flojas (infoproductos, SaaS, coaches).
2. Publica el post y manda DMs.
3. Reescribe 1 landing de muestra (titular + bullets + CTA).
4. Envíala como prueba y pide testimonio.
5. Cobra 49 € por landing completa.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de copywriting

```text
Actúa como copywriter direct response. Te paso esta landing: [pegar URL o texto]. Devuélveme: 3 titulares alternativos, 1 subtítulo, 5 bullets de beneficio, 1 bloque de prueba social y 2 CTAs. Explica en 1 línea por qué cada cambio mejora conversión.
```

## Mensajes de captación (copy)

### Post de captación

```text
✍️ Reescribo gratis la landing de 2 proyectos esta semana. Foco en claridad, beneficio y CTA. Solo pido testimonio. DM 'LANDING'.
```

## Automatización

Plantilla de auditoría de copy (checklist de 12 puntos) + prompt. Entrega en doc listo para pegar.
