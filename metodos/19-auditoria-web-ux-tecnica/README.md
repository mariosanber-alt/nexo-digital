# Auditoría web UX/técnica

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Revisión de una web (velocidad, móvil, claridad, CTA, formularios) con informe de 15 puntos priorizados.

## Quién paga

Pymes con web lenta, fea o sin conversión.

## Tarifa

Gratis (2 primeros) → 49 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 48 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- PageSpeed Insights (gratis)
- Capturas de pantalla
- Canva/PDF
- PayPal

## Paso a paso

1. Analiza 2 webs con PageSpeed.
2. Publica el post y manda DMs.
3. Prepara 1 auditoría (15 mejoras priorizadas por impacto/esfuerzo).
4. Envíala como prueba y pide testimonio.
5. Cobra 49 € por informe completo.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de auditoría web

```text
Actúa como consultor UX/web. Te paso la URL: [pegar]. Analiza: velocidad (PageSpeed), móvil, claridad del mensaje, CTA, formularios, confianza. Devuélveme 15 mejoras priorizadas por impacto/esfuerzo, con captura mental de dónde están. Formato tabla.
```

## Mensajes de captación (copy)

### Post de captación

```text
🔍 Audito gratis la web de 2 pymes esta semana: velocidad, móvil, claridad y CTA. Informe de 15 puntos priorizado. Solo pido testimonio. DM 'WEB'.
```

## Automatización

Checklist de 15 puntos + prompt. PageSpeed da los datos objetivos; el prompt los convierte en plan priorizado.

## Dónde encontrar clientes

LinkedIn de pymes, grupos FB de empresarios, Google (webs lentas en PageSpeed), WhatsApp de conocidos, Cámaras de Comercio.

## Plan B

Audita tu propia web o la de un conocido y úsala de ejemplo.

## Verificación y viabilidad

Una web que no convierte es un problema medible y caro para la pyme. Informe con datos (PageSpeed) = alta credibilidad.
