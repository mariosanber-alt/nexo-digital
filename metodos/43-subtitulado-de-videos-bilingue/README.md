# Subtitulado de vídeos (bilingüe)

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear subtítulos (ES↔EN) para vídeos de creadores, empresas y cursos online.

## Quién paga

Creadores de YouTube/TikTok, empresas con vídeos corporativos y academias.

## Tarifa

2-5 € por minuto de vídeo

| Campo | Valor |
|---|---|
| Tiempo de entrega | 24-48 h |
| Dificultad | Media |
| Primer euro | 1-2 semanas |
| Método de cobro | PayPal/Bizum o plataforma. |

## Material necesario (todo gratis o casi gratis)

- CapCut (subtítulos auto, gratis)
- Whisper
- Aegisub (gratis)
- PayPal

## Paso a paso

1. Domina el flujo: transcripción + sincronización + traducción.
2. Publica tu oferta a creadores y academias.
3. Ofrece 2 min gratis por testimonio.
4. Cobra 2-5 €/minuto según idioma y urgencia.
5. Entrega archivo .srt y subtítulos quemados si se pide.
6. Escala a contratos recurrentes (canales de YouTube).

## Prompts listos para copiar

### Prompt de traducción de subtítulos

```text
Traduce estos subtítulos al [inglés/español] manteniendo longitud similar (máx 2 líneas, 42 caracteres por línea), tono y nombres propios. Formato SRT con timestamps: [pegar].
```

## Mensajes de captación (copy)

### DM a creador

```text
Hola [nombre], hago subtítulos bilingües (ES↔EN) para tus vídeos. Te subtitulo 2 min gratis de tu último vídeo para que veas la calidad. ¿Te interesa?
```

## Automatización

CapCut/Whisper generan el 80% (transcripción y sincronización); el prompt traduce; tú revisas timing. Flujo repetible y escalable.

## Dónde encontrar clientes

YouTube (creadores), LinkedIn, academias online, grupos FB de editores, Upwork/Fiverr.

## Plan B

Subtitula tus propios vídeos y úsalo de portfolio.

## Verificación y viabilidad

El contenido bilingüe multiplica audiencia; demanda real de creadores que quieren llegar a mercados EN. Servicio claro y entregable.
