# Carta de presentación por oferta

> 💼 **Categoría:** Empleo y Carrera · **Origen:** Conversación con DeepSeek

## Qué es

Carta personalizada para una oferta concreta, con keywords de la oferta y conexión con la empresa.

## Quién paga

Buscadores de empleo que aplican a muchas ofertas sin personalizar.

## Tarifa

Gratis (3 primeras) → 9 €/carta o 19 € pack de 3

| Campo | Valor |
|---|---|
| Tiempo de entrega | 24 h |
| Dificultad | Fácil |
| Primer euro | 24-48 h |
| Método de cobro | PayPal, 100% antes de entregar. |

## Material necesario (todo gratis o casi gratis)

- Google Docs
- DeepSeek/ChatGPT
- PayPal

## Paso a paso

1. Elige 3 ofertas reales de portales de empleo.
2. Publica el post y manda DMs.
3. Escribe 1 carta de muestra (250 palabras).
4. Envíala como prueba y pide testimonio.
5. Vende 9 €/carta o 19 € pack de 3.
6. Cobra por PayPal.

## Prompts listos para copiar

### Prompt de carta

```text
Actúa como coach de carrera. Te paso esta oferta: [pegar] y este CV: [pegar]. Devuélveme una carta de 250 palabras que conecte experiencia con las 3 necesidades principales de la oferta, con keywords y sin clichés. Añade 3 bullets de conexión para la entrevista.
```

## Mensajes de captación (copy)

### Post de captación

```text
✉️ Escribo gratis 3 cartas de presentación personalizadas esta semana (adaptadas a la oferta, no plantilla). Solo pido testimonio. DM 'CARTA'.
```

## Automatización

El prompt genera la carta en 2 min; solo revisas. Plantilla base + adaptación por oferta.

## Dónde encontrar clientes

Grupos FB de empleo, LinkedIn #OpenToWork, Discord de búsqueda de empleo, Twitter, WhatsApp de conocidos.
