# Micro-SaaS / plantilla web de pago

> ⚙️ **Categoría:** Automatización y Software · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear una plantilla web o herramienta pequeña (Framer/Webflow/HTML/Notion) y venderla como plantilla o suscripción.

## Quién paga

Freelancers y pymes que necesitan web o herramienta lista para usar.

## Tarifa

29-99 € por plantilla (o 5-15 €/mes suscripción)

| Campo | Valor |
|---|---|
| Tiempo de entrega | 5-10 h por plantilla |
| Dificultad | Alta |
| Primer euro | 2-6 semanas |
| Método de cobro | Gumroad/Lemon Squeezy (comisión ~5-10%). |

## Material necesario (todo gratis o casi gratis)

- Framer/Webflow (free tier)
- Notion (gratis)
- Gumroad/Lemon Squeezy
- GitHub

## Paso a paso

1. Identifica un nicho con necesidad concreta (portfolio de fotógrafos, landing de clínicas, kit de facturación).
2. Construye la plantilla con Framer/Webflow o un sistema en Notion.
3. Empaquetala con instrucciones y vídeo de 3 min.
4. Súbela a Gumroad/Lemon Squeezy (entrega automática).
5. Publica 2-3 demos gratuitas en redes para generar tráfico.
6. Itera y crea una suscripción si el nicho lo justifica.

## Prompts listos para copiar

```text
Actúa como analista de productos. Dame 10 ideas de micro-plantillas/herramientas vendibles en 2026 para nichos concretos (no genéricos), con dolor que resuelven, precio sugerido y canal de promoción.
```

## Mensajes de captación (copy)

### Descripción de venta

```text
Plantilla [nombre]: tu [web/sistema] lista en 1 hora. Incluye [N] secciones, guía de uso y soporte por email. Sin código. Pago único de [precio].
```

## Automatización

Lemon Squeezy/Gumroad gestionan pago + entrega + IVA automáticamente. La plantilla es 100% pasiva tras publicarse.

## Dónde encontrar clientes

Twitter/X #buildinpublic, Product Hunt, Indie Hackers, grupos FB de nicho, Gumroad (búsqueda).

## Plan B

Regala 1 plantilla básica y vende la versión premium.

Mercado global real (las plantillas de Framer/Notion se venden bien). Barrera técnica media-alta; se apoya en los prompts para acelerar diseño y copy.
