# Pitch deck para startups

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Estructura y redacción de un pitch deck de 10 slides (problema, solución, mercado, tracción, equipo, ask).

## Quién paga

Founders pre-seed que buscan inversión o aceleradoras.

## Tarifa

Gratis (2 primeros) → 79 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 72 h |
| Dificultad | Alta |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Google Slides
- Google Docs
- DeepSeek/ChatGPT
- PayPal

## Paso a paso

1. Busca 3 startups pre-seed (LinkedIn, Twitter buildinpublic).
2. Publica el post y manda DMs.
3. Monta 1 deck de muestra (10 slides + notas del orador).
4. Envíalo como prueba y pide testimonio.
5. Cobra 79 € por deck completo.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de pitch deck

```text
Actúa como mentor de startups. Te paso la idea de esta startup: [pegar]. Devuélveme el contenido de 10 slides: problema, solución, mercado (TAM/SAM/SOM), producto, tracción, modelo de negocio, competencia, equipo, roadmap, ask. 3 bullets por slide, tono inversor.
```

## Mensajes de captación (copy)

### Post de captación

```text
🚀 Ayudo gratis a 2 startups a estructurar su pitch deck (10 slides + notas). Solo pido testimonio. DM 'PITCH'.
```

## Automatización

Plantilla de Google Slides con los 10 slides + prompt. Cada deck es adaptar contenido y rediseñar levemente.

## Dónde encontrar clientes

LinkedIn #founder, Twitter #buildinpublic, Discord de startups, Indie Hackers, grupos FB de emprendedores.

## Plan B

Ofrece a un founder conocido.

## Verificación y viabilidad

Ticket alto y demanda real (cada semana se crean cientos de startups). Requiere buen criterio de negocio, pero el prompt hace el 70% del trabajo.
