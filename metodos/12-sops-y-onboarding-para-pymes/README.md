# SOPs y onboarding para pymes

> 🏪 **Categoría:** Negocios Locales y Pymes · **Origen:** Conversación con DeepSeek

## Qué es

Documentación de procesos (SOPs) para que un nuevo empleado pueda incorporarse solo.

## Quién paga

Pymes que contratan sin proceso de onboarding.

## Tarifa

Gratis (2 primeros) → 79 € (5 SOPs)

| Campo | Valor |
|---|---|
| Tiempo de entrega | 72 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Google Docs
- Loom
- PayPal

## Paso a paso

1. Elige 2 pymes que contraten sin proceso (LinkedIn de gerentes).
2. Publica el post y manda DMs.
3. Escribe 1 SOP de muestra (objetivo, pasos, checklist, errores comunes).
4. Envíalo como prueba y pide testimonio.
5. Cobra 79 € por 5 SOPs + checklist de onboarding día 1.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de SOP

```text
Actúa como consultor de operaciones. Te paso la descripción de este proceso de [pyme]: [pegar]. Devuélveme un SOP en formato: objetivo, responsable, materiales, pasos numerados, checklist final y errores comunes. Formato para imprimir.
```

## Mensajes de captación (copy)

### Post de captación

```text
📋 Documento gratis los procesos de 2 pymes esta semana (5 SOPs + onboarding día 1). Solo pido testimonio. DM 'SOP'.
```

## Automatización

Plantilla de SOP (encabezado + pasos + checklist) reutilizable. El prompt convierte una descripción oral en un SOP listo en 10 min.

## Dónde encontrar clientes

LinkedIn de gerentes de pymes, grupos FB de empresarios, WhatsApp de conocidos, Cámaras de Comercio, Discord de operations.

## Plan B

Documenta un proceso de tu propio trabajo y úsalo de ejemplo.

## Verificación y viabilidad

Las pymes con rotación pierden tiempo reentrenando; un onboarding documentado tiene ROI claro. Ticket alto y fácil de demostrar con un ejemplo.
