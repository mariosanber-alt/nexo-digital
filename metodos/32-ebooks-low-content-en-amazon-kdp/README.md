# eBooks low-content en Amazon KDP

> 📦 **Categoría:** Productos Digitales · **Origen:** Método nuevo (creado y verificado)

## Qué es

Publicar cuadernos, diarios, agendas y libros de actividades (low-content) en Amazon KDP.

## Quién paga

Compradores de Amazon globales (regalos, cuadernos temáticos, diarios).

## Tarifa

6-12 € por libro (royalty ~60-70%)

| Campo | Valor |
|---|---|
| Tiempo de entrega | Publicación: 24-72 h por libro |
| Dificultad | Media |
| Primer euro | 2-4 semanas |
| Método de cobro | Amazon paga royalties mensuales por transferencia (60-70% en tapa blanda según precio). |

## Material necesario (todo gratis o casi gratis)

- Amazon KDP (gratis)
- Canva (gratis)
- Cuenta bancaria para royalties

## Paso a paso

1. Crea cuenta en kdp.amazon.com (gratis).
2. Investiga 5 nichos de low-content (diarios de gratitud, cuadernos de recetas, agendas para opositores).
3. Diseña interior (páginas pautadas/dot grid) y portada en Canva.
4. Exporta a PDF con las medidas exactas de KDP (p.ej. 6x9 pulgadas).
5. Sube el libro, fija precio, publica.
6. Repite con variaciones (tapa blanda es la más rentable en low-content).
7. Promociona en Pinterest/Instagram; Amazon aporta tráfico orgánico.

## Prompts listos para copiar

### Prompt de investigación KDP

```text
Actúa como editor de Amazon KDP. Dame 10 nichos de libros low-content rentables en español con baja competencia, el subtítulo exacto y 7 keywords de búsqueda para cada uno.
```

### Prompt de descripción de libro

```text
Actúa como copywriter editorial. Te paso este libro: [título y uso]. Devuélveme: descripción de 150 palabras con beneficios, 7 keywords de Amazon y 3 frases para el campo de subtítulo.
```

## Mensajes de captación (copy)

### Descripción de producto

```text
Este cuaderno de [uso] te ayuda a [beneficio]. Incluye [N] páginas, tamaño práctico y portada premium. Ideal para regalar. [CTA].
```

## Automatización

Una vez validada una portada/interior, crea variaciones cambiando solo portada y título. KDP gestiona impresión, envío y cobro automáticamente (print-on-demand).

## Dónde encontrar clientes

Amazon (búsqueda orgánica), Pinterest, Instagram, grupos FB de nicho.

## Plan B

Empieza con 3 cuadernos de nichos distintos y duplica el que venda.

## Verificación y viabilidad

KDP es gratuito y real; los low-content se venden a largo plazo con catálogo amplio. Requiere volumen (10-30 títulos) para ingresos estables. Sin coste de producción (se imprime bajo demanda).
