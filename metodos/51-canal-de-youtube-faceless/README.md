# Canal de YouTube faceless

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear un canal sin mostrar la cara (top 10, historias, tutoriales con voz IA) y monetizar con AdSense/afiliados.

## Quién paga

Audiencia masiva de YouTube (monetización por publicidad y afiliación).

## Tarifa

Ingresos por AdSense (1-5 €/1000 vistas) + afiliados

| Campo | Valor |
|---|---|
| Tiempo de entrega | 3-6 meses para monetizar |
| Dificultad | Alta |
| Primer euro | 3-6 meses |
| Método de cobro | Google AdSense (pago mensual por transferencia) + comisiones de afiliados. |

## Material necesario (todo gratis o casi gratis)

- CapCut/DaVinci (edición)
- Voz IA o tu voz
- Canva/Photopea (imágenes)
- Bing Image Creator

## Paso a paso

1. Elige 1 nicho con alto CPM (finanzas, IA, curiosidades, salud).
2. Crea 10 vídeos de 8-12 min con guion + voz IA + imágenes/stock.
3. Optimiza títulos, miniaturas y descripciones (SEO).
4. Publica 2-3 vídeos/semana con constancia.
5. Alcanza 1000 suscriptores + 4000 h para monetizar con AdSense.
6. Añade enlaces de afiliados desde el primer día.

## Prompts listos para copiar

### Prompt de guion

```text
Actúa como guionista de YouTube. Te paso el tema: [pegar]. Devuélveme un guion de 8 min para canal faceless: hook (15 s), 5 secciones con datos concretos, transiciones y CTA final. Tono divulgativo y ágil.
```

### Prompt de miniatura/título

```text
Actúa como estratega de YouTube. Para este vídeo: [tema], dame 5 títulos con alto CTR (curiosidad + beneficio) y 3 ideas de miniatura con el texto exacto a poner.
```

## Automatización

Flujo en cadena: prompt de guion → voz IA → montaje con plantilla → miniatura con plantilla. Publica con programación automática de YouTube.

## Dónde encontrar clientes

YouTube (búsqueda y sugeridos), Reddit (subreddits de nicho), Pinterest.

## Plan B

Empieza con 3 vídeos y mide CTR/duración antes de escalar.

## Verificación y viabilidad

Real pero de arranque lento (3-6 meses) y requiere constancia y volumen. Es un activo de largo plazo, no un primer euro rápido. Alto potencial si se elige bien el nicho.
