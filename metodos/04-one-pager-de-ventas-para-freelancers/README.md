# One-pager de ventas para freelancers

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Página de presentación de servicios (quién eres, qué haces, para quién, precio, CTA) en PDF/Canva.

## Quién paga

Freelancers que venden por DM pero no tienen nada que enviar.

## Tarifa

Gratis (3 primeros) → 19 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 24 h |
| Dificultad | Fácil |
| Primer euro | 24-48 h |
| Método de cobro | PayPal, 100% antes de entregar. |

## Material necesario (todo gratis o casi gratis)

- Canva (gratis)
- Google Docs
- PayPal

## Paso a paso

1. Crea una plantilla de one-pager en Canva (1 página).
2. Publica el post en grupos de freelancers.
3. Haz 1 one-pager de muestra con un servicio real.
4. Envía la muestra y pide testimonio.
5. Cobra 19 € por one-pager personalizado.
6. Reutiliza la plantilla para entregar en 30-45 min.

## Prompts listos para copiar

### Prompt de copy

```text
Actúa como copywriter. Te paso los servicios de este freelance: [pegar]. Devuélveme el copy de un one-pager: titular, subtítulo, 3 bloques de servicio con beneficio, prueba social (si hay), CTA y precio orientativo. Máximo 200 palabras.
```

## Mensajes de captación (copy)

### Post de captación

```text
📄 Hago gratis un one-pager de servicios a 3 freelancers esta semana. Es la página que envías cuando alguien pregunta '¿qué haces?'. Solo pido testimonio. DM 'PAGINA'.
```

## Automatización

Plantilla de Canva con bloques rellenables. El prompt genera el copy; solo pegas y ajustas colores/logo.

## Dónde encontrar clientes

Grupos FB de freelancers, Twitter #freelance, Discord de diseñadores/devs, LinkedIn de freelancers, Instagram de creativos.

## Plan B

Ofrece a 3 freelancers que conozcas.

## Verificación y viabilidad

Los freelancers necesitan 'algo que enviar' cuando les preguntan qué hacen; un one-pager profesional sube su tasa de cierre. Demanda real y producto fácil de entregar.
