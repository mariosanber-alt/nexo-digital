# Voice-over con IA para empresas

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Conversación con DeepSeek

## Qué es

Locución con IA para vídeos corporativos, tutoriales o anuncios.

## Quién paga

Empresas que hacen vídeos pero no quieren pagar un locutor.

## Tarifa

Gratis (2 primeros) → 25 € por vídeo (hasta 2 min)

| Campo | Valor |
|---|---|
| Tiempo de entrega | 24 h |
| Dificultad | Media |
| Primer euro | 48-72 h |
| Método de cobro | PayPal, 100% antes de entregar. |

## Material necesario (todo gratis o casi gratis)

- ElevenLabs (o TTS gratuito)
- Audacity (gratis)
- Google Docs
- PayPal

## Paso a paso

1. Crea cuenta en una herramienta TTS (ElevenLabs free tier o alternativa gratuita).
2. Publica el post y manda DMs.
3. Genera 1 locución de muestra (script + MP3).
4. Envíala como prueba y pide testimonio.
5. Cobra 25 € por vídeo de hasta 2 min.
6. Cobra por PayPal antes de entregar.

## Prompts listos para copiar

### Prompt de guion de locución

```text
Actúa como guionista de locución. Adapta este texto para lectura en voz alta: [pegar]. Añade pausas marcadas, respiraciones y énfasis. Máximo 1,5 palabras por segundo. Devuélveme el texto final listo para TTS.
```

## Mensajes de captación (copy)

### Post de captación

```text
🎙️ Genero gratis la locución con IA de 2 vídeos corporativos esta semana. Voz natural, español e inglés. Solo pido testimonio. DM 'VOZ'.
```

## Automatización

Flujo: prompt de guion → TTS → exportar MP3 → entregar. Guarda un banco de voces/tonos por tipo de cliente para reutilizar.

## Dónde encontrar clientes

Grupos FB de marketing de vídeo, LinkedIn de productoras, YouTube (canales con voz robótica), Twitter #videomarketing, Discord de creadores.

## Plan B

Genera voz para un vídeo tuyo y úsalo de portfolio.

## Verificación y viabilidad

NOTA: verifica los términos actuales de ElevenLabs free tier (atribución/límites de uso comercial). Si el plan gratis limita el uso comercial, usa una TTS gratuita con licencia comercial (Microsoft Edge TTS, Google TTS vía herramienta) o genera con la cuenta del propio cliente.
