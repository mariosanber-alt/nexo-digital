# Edición y transcripción de podcast

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Conversación con DeepSeek

## Qué es

Transcripción + limpieza + show notes + 3 clips para redes por episodio.

## Quién paga

Podcasters pequeños sin editor.

## Tarifa

Gratis (2 primeros) → 39 €/episodio

| Campo | Valor |
|---|---|
| Tiempo de entrega | 48 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Whisper (gratis) o Groq
- CapCut
- Google Docs
- PayPal

## Paso a paso

1. Elige 2 podcasts pequeños sin editor.
2. Publica el post y manda DMs.
3. Transcribe 1 episodio de muestra (Whisper gratis).
4. Envía transcripción + show notes + 3 clips.
5. Cobra 39 €/episodio.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de show notes

```text
Actúa como editor de podcast. Te paso la transcripción: [pegar]. Devuélveme: transcripción limpia (sin muletillas), show notes de 100 palabras, 5 timestamps con tema, 3 ideas de clip con minuto de inicio/fin y texto de gancho.
```

## Mensajes de captación (copy)

### Post de captación

```text
🎙️ Transcribo y edito gratis 1 episodio de podcast a 2 podcasters esta semana (show notes + 3 clips). Solo pido testimonio. DM 'PODCAST'.
```

## Automatización

Flujo: transcribir con Whisper → prompt de show notes → cortar 3 clips con CapCut. Repetible por episodio.

## Dónde encontrar clientes

Twitter de podcasters, grupos FB de podcasting, Discord de creadores, Instagram de podcasts pequeños, LinkedIn.

## Plan B

Transcribe un episodio tuyo o de un conocido y úsalo de ejemplo.

## Verificación y viabilidad

El podcast crece y los creadores no quieren editar. Servicio recurrente por episodio; el paquete show notes + clips aporta mucho valor.
