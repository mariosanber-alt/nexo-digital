# Guion de curso corto

> 📦 **Categoría:** Productos Digitales · **Origen:** Conversación con DeepSeek

## Qué es

Estructura y guion de un curso de 3-5 lecciones (objetivo, módulos, guiones, ejercicios).

## Quién paga

Expertos que quieren lanzar su primer curso pero no saben estructurarlo.

## Tarifa

Gratis (2 primeros) → 79 €

| Campo | Valor |
|---|---|
| Tiempo de entrega | 72 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Google Docs
- DeepSeek/ChatGPT
- PayPal

## Paso a paso

1. Elige 2 expertos con conocimiento pero sin curso.
2. Publica el post y manda DMs.
3. Escribe 1 lección de muestra.
4. Envíala como prueba y pide testimonio.
5. Cobra 79 € por guion completo (3-5 lecciones + ejercicios).
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de curso

```text
Actúa como diseñador instruccional. Te paso el tema del curso: [pegar]. Devuélveme: título, promesa, 3-5 módulos con objetivo, guion por lección (300 palabras), 1 ejercicio por módulo y criterio de éxito.
```

## Mensajes de captación (copy)

### Post de captación

```text
🎓 Estructuro gratis el guion de un curso corto a 2 expertos esta semana (3-5 lecciones + ejercicios). Solo pido testimonio. DM 'CURSO'.
```

## Automatización

Plantilla de guion (objetivo → módulos → lección → ejercicio). El prompt convierte el conocimiento del experto en un curso vendible.

## Dónde encontrar clientes

LinkedIn de formadores, grupos FB de infoproductores, Twitter #infoproducto, Discord de creadores, Instagram de coaches.

## Plan B

Estructura un curso tuyo y úsalo de ejemplo.

## Verificación y viabilidad

El mercado infoproducto es enorme; el cuello de botella del experto es estructurar. Ticket alto y cliente con presupuesto.
