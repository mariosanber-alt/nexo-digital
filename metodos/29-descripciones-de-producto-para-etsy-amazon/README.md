# Descripciones de producto para Etsy/Amazon

> 📣 **Categoría:** Marketing y Ventas · **Origen:** Conversación con DeepSeek

## Qué es

Título SEO + descripción + tags para 10 productos en marketplaces.

## Quién paga

Vendedores de Etsy/Amazon con listings flojos.

## Tarifa

Gratis (10 productos) → 29 € por 20

| Campo | Valor |
|---|---|
| Tiempo de entrega | 72 h |
| Dificultad | Media |
| Primer euro | 72 h |
| Método de cobro | 50% adelantado (PayPal). |

## Material necesario (todo gratis o casi gratis)

- Google Sheets
- DeepSeek/ChatGPT
- PayPal

## Paso a paso

1. Elige 2 vendedores con pocas ventas.
2. Publica el post y manda DMs.
3. Reescribe 2 productos de muestra.
4. Envíalos como prueba y pide testimonio.
5. Cobra 29 € por 20 productos.
6. Cobra 50% por adelantado.

## Prompts listos para copiar

### Prompt de listings

```text
Actúa como copywriter de marketplaces. Te paso estos productos: [nombre + características]. Devuélveme por producto: título SEO (140 caracteres Etsy / 200 Amazon), 5 bullets, descripción de 100 palabras y 13 tags. Formato tabla.
```

## Mensajes de captación (copy)

### Post de captación

```text
🛍️ Reescribo gratis los listings de 10 productos de 2 vendedores de Etsy/Amazon esta semana (SEO + conversión). Solo pido testimonio. DM 'LISTING'.
```

## Automatización

El prompt genera la tabla completa; entrega en Google Sheet. Escala a decenas de productos por cliente.

## Dónde encontrar clientes

Etsy (buscador, vendedores con pocas ventas), grupos FB de Etsy, Reddit r/Etsy, Twitter #EtsySeller, Discord de ecommerce.

## Plan B

Reescribe un producto de un amigo o uno tuyo y úsalo de ejemplo.

## Verificación y viabilidad

Los listings optimizados suben ventas en marketplaces; nicho global con clientes acostumbrados a pagar por SEO.
