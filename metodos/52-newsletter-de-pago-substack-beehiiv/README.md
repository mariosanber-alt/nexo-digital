# Newsletter de pago (Substack/Beehiiv)

> 🎬 **Categoría:** Contenido y Creadores · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear una newsletter nicho con suscripción gratuita y opción de pago (contenido premium).

## Quién paga

Profesionales que quieren información curada de un nicho (IA, finanzas, marketing, empleo).

## Tarifa

5-10 €/mes por suscriptor de pago

| Campo | Valor |
|---|---|
| Tiempo de entrega | 2-3 meses para tracción |
| Dificultad | Media |
| Primer euro | 1-3 meses |
| Método de cobro | Substack/Beehiiv gestionan el cobro recurrente (comisión ~10%). |

## Material necesario (todo gratis o casi gratis)

- Substack o Beehiiv (gratis)
- Google Docs
- LinkedIn/X para difundir
- Stripe (integrado)

## Paso a paso

1. Elige 1 nicho que sigues de cerca y que tenga audiencia dispuesta a pagar.
2. Publica 1 edición semanal de calidad (curated + análisis propio).
3. Ofrece la suscripción gratis al inicio para crecer la base.
4. Añade un nivel de pago (5-10 €/mes) con contenido extra (análisis, plantillas, comunidad).
5. Promociona en LinkedIn/X con hilos que enlacen a la newsletter.
6. Convierte ~2-5% de gratuitos en pagos.

## Prompts listos para copiar

### Prompt de edición semanal

```text
Actúa como editor de newsletter. Te paso el tema de la semana: [pegar]. Devuélveme: titular, subtítulo, 5 puntos clave con análisis propio, 1 recurso recomendado y CTA. Tono [profesional/cercano]. 500 palabras.
```

## Mensajes de captación (copy)

### Hilo de LinkedIn

```text
🧵 [Titular con gancho]. 5 claves de [tema] que casi nadie cuenta. Lo desarrollo cada semana en mi newsletter [enlace]. Abro hilo 👇
```

## Automatización

Substack/Beehiiv gestionan suscripciones, cobro (Stripe) y envío automático. El prompt acelera cada edición a 30 min.

## Dónde encontrar clientes

LinkedIn, X/Twitter, comunidades de nicho (Reddit/Discord), YouTube.

## Plan B

Empieza gratis 3 meses y activa el pago cuando tengas 500+ suscriptores.

## Verificación y viabilidad

Modelo validado (Substack/Beehiiv son gratuitos). Requiere constancia y nicho concreto; el pago llega con base de suscriptores. Ingreso recurrente.
