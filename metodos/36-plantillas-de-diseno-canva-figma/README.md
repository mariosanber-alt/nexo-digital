# Plantillas de diseño (Canva/Figma)

> 📦 **Categoría:** Productos Digitales · **Origen:** Método nuevo (creado y verificado)

## Qué es

Crear y vender plantillas de diseño: posts de Instagram, presentaciones, CVs, invitaciones, kits de marca.

## Quién paga

Pequeños negocios y creadores que no saben diseñar.

## Tarifa

8-25 € por kit de plantillas

| Campo | Valor |
|---|---|
| Tiempo de entrega | 2-3 h por kit |
| Dificultad | Media |
| Primer euro | 2-4 semanas |
| Método de cobro | Gumroad (10%) / Payhip (5%) / Etsy (6,5% + 0,20 €). |

## Material necesario (todo gratis o casi gratis)

- Canva (gratis) o Figma (gratis)
- Gumroad/Payhip (gratis)
- Pinterest/Instagram

## Paso a paso

1. Elige 1 formato con demanda (kit de 30 posts Instagram, plantilla CV, menú, presentación).
2. Diseña el kit (10-30 plantillas editables y coherentes).
3. Exporta enlace de plantilla editable (Canva) o archivo (Figma).
4. Súbelo a Gumroad/Payhip con portada y descripción.
5. Promociona en Pinterest e Instagram con un post de muestra.
6. Reutiliza la estructura para crear más kits de otros nichos.

## Prompts listos para copiar

### Prompt de kit de plantillas

```text
Actúa como diseñador. Te paso el negocio/uso: [pegar]. Diseña la estructura de un kit de 20 plantillas de Canva: tipos de página, jerarquía visual, paleta y tipografía, y el copy de cada plantilla. Devuélvemelo en lista para montarlo.
```

## Mensajes de captación (copy)

### Descripción Gumroad

```text
Kit de [N] plantillas editables en Canva para [uso]. Cambia textos y colores en segundos. Incluye guía de uso y fuentes. Perfecto para [público].
```

## Automatización

Gumroad/Payhip entrega el enlace automáticamente. Las plantillas son 100% pasivas: se crean una vez y se venden infinitas.

## Dónde encontrar clientes

Pinterest, Instagram, Etsy, Gumroad (búsqueda), grupos FB de emprendedores.

## Plan B

Regala 1 plantilla a cambio de email y vende el kit completo.

## Verificación y viabilidad

Mercado real y escalable; los kits de redes sociales y CV tienen demanda constante. Sin coste de producción, solo tiempo de diseño.
